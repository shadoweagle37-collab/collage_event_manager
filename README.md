## 📖 Overview

**EventHub** is a front-end College Event Management System that allows organizers to manage college events and participants through an intuitive dashboard.

The project demonstrates modern UI design, responsive layouts, interactive dashboards, LocalStorage data management, charts, filtering, searching, exporting, and CRUD operations.
